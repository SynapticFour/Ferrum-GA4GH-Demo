# Ferrum GA4GH demonstration

This demonstration runs a tagged Ferrum on a laptop so a person can see file ingest, a workflow, and a task finish on that machine.

For someone who wants to watch DRS, WES, and TES on a laptop, and for someone judging what that run is evidence of.

**Status: No public status is recorded** for this demonstration. It follows [Ferrum](https://github.com/SynapticFour/Ferrum) at pin **v0.3.2** (`2bd147c99735866ac9cfb530f62ef984c8efce8b` in [PINNED_VERSIONS.txt](PINNED_VERSIONS.txt)). That pin is deliberate. Registry: WEB-VERSION-001. The website sentence is this demo pin. It is not the current Ferrum git tag. The pin is not a statement that Ferrum's default branch is v0.3.2. Ferrum's default branch is newer. The pin is not "current Ferrum is v0.3.2".

## What a run shows

- A successful `./run` shows that the laptop stack can ingest files via DRS, submit a WES run that TES executes (Cromwell or Nextflow and GATK), and write a hap.py JSON for that slice.
- The numbers below are pipeline smoke. They are not a GIAB publication result.

## What a run does not show

- GIAB or Platinum genome-wide concordance, clinical validity, or GA4GH conformance. Conformance checks are [HelixTest](https://github.com/SynapticFour/HelixTest).
- Africa or field features, or that the Dockstore GATK germline WDL ran. It is fetched, not executed.
- A green run is a technical signal for this pinned tag. It is not a certificate and not a clinical pilot.

> This repository documents technical capabilities. It is not legal advice and does not provide regulatory certification. hap.py Precision/Recall/F1 here are slice-level pipeline smoke, not a publication GIAB result.

## Quick start

Prerequisites: Docker, about 8 GB RAM, about 20 GB disk, `git`, `python3`, `curl`, and `bash`. The run clones the pinned Ferrum commit. It needs a network for that clone, for images, and for public data.

```bash
make up
```

`make up` is `./run`. You should see `results/RUN_MANIFEST.json`. Read that file first. Stop with `make down`. Remove volumes with `make destroy`. The default `./run` resets volumes unless `--no-reset`.

**Demo-only security:** the gateway reaches Docker through **docker-socket-proxy**. Nested TES tasks may still receive a host-daemon `docker.sock` bind so Cromwell can start GATK. Crypt4GH `node.sec` is generated at `./run` time and gitignored. Do not copy this compose posture to a hospital network.
